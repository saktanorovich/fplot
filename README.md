# fplot Project

**fplot** — a lightweight C# demo app to build 2d curves.

---

## 📋 Prerequisites

- **Operating System**: macOS (arm64) / Win
- **Compiler**: net9.0 support
- **Tools**:
  - `dotnet` to build the project
  - `git` to clone the repository

---

## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/saktanorovich/fplot.git
   cd fplot
2. **Build the project**
   ```bash
   cd ./src
   dotnet restore
   dotnet build
3. **Run the application**
   ```bash
   cd ./FPlot
   dotnet run
